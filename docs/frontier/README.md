# ACS research continuations

This is an ongoing record of useful research deltas: stronger derivations, independent checks, corrections, counterexamples, newly testable questions, and exact input gates. Each dated package preserves the evidence and limitations of that pass. There is no claim of global exhaustion or a final completed theory.

The queue distinguishes carried-forward records from new work in the current pass. A reproducibility check is recorded separately from a new derivation. Cross-method verification identifies what is shared between methods. New statements retain their model and hypothesis boundaries, and failed attempts remain part of the evidence.
